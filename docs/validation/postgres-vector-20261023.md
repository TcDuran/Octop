## 隔离范围

- 本地容器：imprv-pgvectorscale-18；连接限 127.0.0.1:5432。
- 管理连接使用 postgres 库；源 octop 库只读获取已有 provider 配置和扩展状态，没有安装扩展或修改业务表。
- 仅在随机创建、登记 OID 的临时库中启用 vector 扩展和写入合成数据；不安装 vectorscale，不下载本地模型，不启用 IM。
- 诊断代码位于独立 worktree 的 data/opengauss/pg-vector-20261023，凭证只在进程内读取，不写入代码或报告。本轮未修改产品代码、部署配置或生产依赖。
